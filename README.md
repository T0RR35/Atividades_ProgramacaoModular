# Programação Modular

Repositório de estudos e prática de **Programação Modular**, realizada no segundo período de Engenharia de Software, reunindo listas de exercícios, exemplos comentados e implementações organizadas por tópico.

## 📚 Sobre

Acesse as diferentes branches do projeto para ver diferentes práticas.

## 🚀 Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/T0RR35/Atividades_ProgramacaoModular
   ```
2. Entre na branch desejada (lista, prática ou projeto):
   ```bash
   git switch nome-da-branch
   ```
3. Execute o arquivo conforme a linguagem utilizada, por exemplo:

## 🧩 Tópicos abordados
 
- Programação Orientada a Objetos (OO)
- Encapsulamento
- Polimorfismo
- Acoplamento
- Coleções
- Herança
- Interfaces

- Iteradores e Enumeradores
- Tratamento de Exceções
- Testes Unitários

- Tipos Opcionais e Programação Genérica
- Princípios SOLID
- Padrões de Projeto Criacionais
- Padrões de Projeto Estruturais
- Padrões de Projeto Comportamentais
